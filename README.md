# Sacada Cultural

## Description

Sacada Cultural is a mobile app for cultural events. The app helps visitors find events and helps organizers create and manage their own events.

Users can create an account, log in, see event feeds, view event details, filter events, and access their event history. Organizers can also register new events and check the status of their events.

## Features

- User login and registration
- Password recovery
- Visitor event feed
- Organizer event feed
- Event details screen
- Event filters
- Event registration for organizers
- Event status management
- Visitor and organizer history
- User profile and settings
- Poster image upload for events
- Firebase integration for data and authentication

## Technologies

- React Native
- Expo
- JavaScript
- TypeScript
- Firebase
- Firestore
- React Navigation
- React Native Web

## How to Run

1. Clone the repository.

```bash
git clone <repository-url>
```

2. Open the project folder.

```bash
cd eventos-culturais-mobile
```

3. Install the dependencies.

```bash
npm install
```

4. Configure the Firebase environment variables in a `.env` file.

5. Start the app.

```bash
npm start
```

6. Choose where to run the app:

```bash
npm run android
npm run ios
npm run web
```
